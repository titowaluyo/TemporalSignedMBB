# TemporalSignedMBB

Code, tests and result files for the article

> Purboyo TW. Ground-truth benchmarking of signed, directed lagged connectivity:
> TemporalSignedMBB from a simulated gut-brain model to neural data.
> *Cognitive Neurodynamics* (2026).

The package contains the `tsmbb` Python modules, the entry-point scripts of the original
submission and of the revision, thirteen unit tests, the result files (JSON and NPZ) from which
every number in the article is read, and the figure files. The same package is Online Resource 1
(ESM_1.zip) of the article.

## 1. Install

Python 3.13 is required (the pinned packages need Python 3.12 or newer).

**Option A, conda**

```
conda env create -f environment.yml
conda activate tsmbb
pip install --no-deps -r requirements-lingam.txt
```

**Option B, plain Python 3.13 with a virtual environment**

```
python -m venv .venv
.venv\Scripts\activate            (Windows)
source .venv/bin/activate         (macOS, Linux)
pip install -r requirements.txt
pip install --no-deps -r requirements-lingam.txt
```

The second `pip` line installs the DirectLiNGAM comparator, which only `neural_revision.py` uses.
It has to be installed with `--no-deps` because `lingam` 1.13.0 and `pygam` 0.12.0 declare an older
SciPy than the SciPy 1.18.1 used for the article; both run correctly with it. `pip check` will
report these two declared conflicts; that is expected.

## 2. Check the installation (about 10 seconds)

```
python -m pytest -q tests
```

Expected output: `13 passed`.

## 3. Reproduce the results

All commands are run from this folder. Every script writes into `results/` (figures into
`figures_rev/`), replacing the shipped files with identical content. Times are for two CPU cores.

| Command | What it reproduces | Time |
|---|---|---|
| `python seed42_revised.py` | illustrative dataset, seed 42 (Table 3, Figs. 1 to 3) | 15 s |
| `python mc_group.py main 1001 30 2` | group-level main scenario, 30 replications | 20 min |
| `python mc_group.py null 2001 50 2` | inferential null, 50 replications | |
| `python mc_group.py <scenario> 3001 20 2` | `correct initdiag tanh lag2 glv t3 driver hetero nonadd weak combined` | |
| `python motif_mc.py 2` | signed motifs | |
| `python clr_phi_checks.py 2` | omitted CLR coordinate, phi stability, SPTS scales | |
| `python lioness_check.py 2` | LIONESS against subject-specific truth | |
| `python comparators_mgb.py 10 2` | external comparators, microbiome benchmark | |
| `python neural_mass_bench.py 20 2` | Wilson-Cowan benchmark | |
| `python get_data.py` then `python neural_revision.py` | NetSim and EEG analyses | 4 min |
| `python mc_subject.py <label> <seed> <R> 2` | subject-level and design replications (labels and seeds in `run_revision.sh`) | 25 min per replication |
| `python aggregate_group.py` and `python aggregate_subject.py` | summaries read by the article | 2 s |
| `python fig1_design_rev.py` and `python make_figures_rev.py` | Figs. 1 to 9 | |

The last argument of the Monte Carlo scripts is the number of worker processes. On Linux or macOS
(or Git Bash on Windows) the whole pipeline runs with `bash run_revision.sh`; it takes many hours.

The scripts of the original submission (`run_all.py`, `design_factor.py`, `neural_demo.py`,
`make_figures.py`, `make_fig7.py`, `fig1_design.py`) are kept unchanged; see
`README_original_submission.txt`. `run_all.py` contains the group-membership error that the
revision corrects (Section 2.13 of the article).

## 4. Data

No empirical microbiome data are used. All simulated data are generated by `tsmbb/generator.py`
from the seeds given in the scripts (seed 42 for the illustrative dataset).

The neural-data scripts use two public datasets that need no registration. `python get_data.py`
downloads them into `data/` and verifies them against `data_checksums.sha256`:

- NetSim simulation 3 (Smith et al. 2011) in NumPy format, from
  <https://github.com/sakhanna/SRU_for_GCI> (folder `data/netsim`);
- the EEGLAB tutorial recording, from <https://github.com/sccn/eeglab>
  (`sample_data/eeglab_data.set` and `eeglab_data.fdt`).
